# Day 4: Retail Cleaning + EDA Challenge[cite: 1]

This repository contains the solution and deliverables for the Day 4 Retail Cleaning and Exploratory Data Analysis (EDA) Challenge[cite: 1].

## 📋 Challenge Overview
The objective is to apply a full data cleaning and analysis workflow to seven retail CSV files[cite: 1]:
* **Data Profiling:** Inspect shape, data types, missing values, duplicates, and key category counts[cite: 1].
* **Cleaning & Deduplication:** Remove exact duplicates from customers, orders, and order_items; clean currency fields in products, order_items, and payments[cite: 1].
* **Normalization & Parsing:** Normalize `customers.gender` and `products.category`, and parse mixed date fields[cite: 1].
* **Validation & Flagging:** Flag invalid ages, zero quantities, inconsistent refund records, and orphan IDs[cite: 1].
* **Analysis & Documentation:** Build an item-level analysis table, answer at least 5 EDA questions, and document at least 5 cleaning decisions (what changed, why, and how it was verified)[cite: 1].

## 📦 Deliverables[cite: 1]
* Working Jupyter Notebook / Python script[cite: 1]
* Cleaned output files[cite: 1]
* Item-level analysis table and written findings[cite: 1]

## 🛠️ Time Box & Approach[cite: 1]
Prioritized correct reasoning and logical justifications for every cleaning step over fixing every possible anomaly[cite: 1].
